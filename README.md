# IT应用资产管理系统 · 前端页面（ITAM Platform）

基于《IT应用资产管理系统特性与功能梳理》需求文档开发的前端演示系统。**原生 HTML + CSS + JavaScript，零构建、零外部依赖、可离线运行**，内置完整 Mock 数据与浏览器本地持久化。

## 一、快速运行

直接双击 `index.html` 即可（推荐 Chrome / Edge）。

如需以服务方式预览（避免个别浏览器对 file:// 的本地存储限制）：

```bash
# 在本目录执行任意一种
python -m http.server 8080
npx serve .
```

然后访问 http://localhost:8080

## 二、目录结构

```
IT应用资产管理系统前端/
├── index.html            页面外壳：导航 / 顶栏 / 内容区 / 抽屉 / 弹窗容器
├── css/styles.css        设计令牌与全部组件样式（无需任何 CSS 框架）

└── js/view-extra.js      拓扑、报表中心、成本、合规、权限审计、开放集成
```

## 四、权限演示

顶栏「当前角色」可切换 6 个角色（系统管理员 / 架构管理员 / 资产管理员 / License 管理员 / 审计员 / 只读用户）。切换后：
- 无权限的导航项会置灰并提示；
- 新增、编辑、删除、导出、审批等按钮自动隐藏或禁用；
- 权限矩阵页可直接勾选修改任意角色权限并即时生效。

## 五、数据说明

- 所有数据均为演示用 Mock 数据，首次打开自动写入浏览器 `localStorage`；
- 所有增删改、审批、流转、配置调整都会即时保存到本地，刷新不丢失；
- 点击左下角「恢复演示数据」可一键还原初始数据。

## 六、接入真实后端

页面内所有取数集中在 `js/data.js` 与 `js/core.js` 的 `Store` 对象；接后端时替换 `Store.load/save` 与各视图的 `listXxx()` 数据来源即可，界面与交互无需改动。建议 API 约定见「开放集成」页中的接口目录。
